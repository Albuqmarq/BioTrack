# BioTrack — Gestão Inteligente de Ativos Biológicos

> **MVP desenvolvido para a disciplina de Gestão de Projetos**  
> Residência em RFID — Easy

---

## Sobre o Projeto

O **BioTrack** é um sistema de rastreabilidade em tempo real para ativos biológicos (sangue, órgãos, tecidos) em hospitais, utilizando tecnologia **RFID UHF passiva**.

Hospitais operam como "ilhas" — a falta de dados compartilhados entre unidades impede que um ativo disponível em um local salve uma vida em outro. O BioTrack resolve isso com:

- **Tags sensoriais RFID UHF** — identificam o ativo e monitoram temperatura sem bateria
- **Portais automatizados** — registram entrada, saída e movimentação interna via rádio frequência
- **Rede de colaboração** — software centralizado que conecta estoques de hospitais parceiros

---

## Funcionalidades do MVP

| Módulo | Descrição |
|---|---|
| Dashboard | KPIs em tempo real, alertas ativos, categorias de estoque |
| Estoque Interno | Tabela completa de ativos com temperatura, localização e validade |
| Detalhe do Ativo | Gráfico de histórico de temperatura das últimas 24h por TAG |
| Logística Externa | Rastreamento de transporte entre hospitais com progresso em tempo real |
| Histórico | Todos os eventos RFID registrados automaticamente via portais |
| Suporte Técnico | Chat integrado com o time BioTrack (dentro e fora do sistema) |
| Alertas Críticos | Modal de alerta automático com notificação ao suporte |

## Como Rodar

Este projeto é um **arquivo HTML único** — não precisa de servidor, instalação ou dependências.

**Basta abrir o arquivo no navegador:**

1. Faça o download do repositório (botão verde `Code` → `Download ZIP`) ou clone:
   ```bash
   git clone https://github.com/SEU_USUARIO/biotrack.git
   ```
2. Abra a pasta e dê duplo clique em `biotrack_v5.html`
3. O sistema abre direto no navegador

> Funciona em qualquer navegador moderno: Chrome, Firefox, Edge, Safari.
